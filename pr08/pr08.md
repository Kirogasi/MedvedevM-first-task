## 7. Контрольные вопросы

**1. Пять мест автозапуска в Linux и их привилегии:**

| Место | Уровень привилегий |
|-------|-------------------|
| /var/spool/cron/crontabs/root | root |
| /var/spool/cron/crontabs/$USER | пользователь |
| ~/.config/systemd/user/ | пользователь (без root) |
| /etc/systemd/system/ | root |
| ~/.bashrc | пользователь |

**2. Чем lsof отличается от ss?**
- ss показывает только сетевые соединения и порты
- lsof показывает ВСЕ открытые файлы, включая сокеты, пайпы, обычные файлы

**3. Что означает (deleted) в lsof?**
Файл был удалён с диска, но процесс всё ещё держит его открытым. Вредоносы так маскируются.

**4. Нужен ли root для user systemd-сервиса?**
Нет, root не нужен. Это опасно, потому что обычный пользователь может прописать автозапуск без прав администратора.

**5. Как отличить настоящий системный процесс от поддельного?**
`systemctl status имя` — покажет настоящий unit-файл и его происхождение. `ls -la /proc/PID/exe` — покажет реальный путь к исполняемому файлу.

**6. Однострочник для поиска исполняемых файлов в /tmp и /var/tmp:**
`find /tmp /var/tmp -type f -executable 2>/dev/null`
